## Результати

### SQL-скрипти
- SQL-скрипти включені у файл `init.sql`, що містить усі оператори `CREATE TABLE` та `INSERT` у порядку. Додані коментарі для ідентифікації кожної таблиці.

### Підсумок остаточної схеми
- **Таблиця Читачів**: Зберігає інформацію про членів бібліотеки.
  - **Стовпці**: `member_id` (первинний ключ), `name`, `address`, `phone`, `email`
  - **Обмеження**: `email` має бути унікальним.

- **Таблиця Книг**: Містить деталі про книги в бібліотеці.
  - **Стовпці**: `book_id` (первинний ключ), `title`, `author`, `genre`, `published_year`
  - **Обмеження**: `title` не може бути null.

- **Таблиця Замовлень**: Записує позики книг членами.
  - **Стовпці**: `order_id` (первинний ключ), `member_id` (зовнішній ключ), `book_id` (зовнішній ключ), `order_date`, `return_date`
  - **Обмеження**: `member_id` посилається на `Members(member_id)`, `book_id` посилається на `Books(book_id)`.

### Доказ заповнення даних
- Кожна таблиця була заповнена щонайменше 3-5 рядками даних. Докази заповнення даних можна знайти у файлі `init.sql` або через скріншоти результатів запитів.

### Скріншоти
- Скріншоти з pgAdmin, що показують таблиці, інструмент запитів або результати запитів `SELECT *`, включені для підтримки оцінки.

## Критерії оцінювання
- **Коректність схеми**: Усі необхідні таблиці існують з правильними стовпцями та типами даних, що відображають вашу ER-модель.
- **Синтаксис SQL**: Оператори `CREATE TABLE` та `INSERT` виконуються без помилок у PostgreSQL.
- **Визначення ключів**: Кожна таблиця має відповідний первинний ключ, а зовнішні ключі правильно представляють зв'язки, забезпечуючи цілісність даних.
- **Використання обмежень**: Обмеження використовуються змістовно (наприклад, `NOT NULL` для обов'язкових полів, `UNIQUE`, де потрібно, `CHECK` для будь-яких правил даних).
- **Узгодженість даних**: Вибіркові дані узгоджуються зі схемою (наприклад, значення зовнішнього ключа відповідають існуючим первинним ключам, немає null-значень, де це заборонено, значення задовольняють умови `CHECK`).
- **Документація**: Пояснення схеми є чітким та точним. (Таблиці та ключі повинні бути чітко описані.)
