## Процес виконання та ключові кроки

### 1. Налаштування та підготовка

Спочатку я встановив необхідне середовище:
- Запустив Docker контейнер з PostgreSQL через `docker-compose up -d`
- Підключився до бази даних за допомогою psql або GUI клієнта
- Переконався, що все готово до запуску скриптів

### 2. Створення структури БД (init.sql)

Я виконав скрипт `init.sql`, щоб:
- Створити таблиці з необхідною структурою
- Визначити первинні ключі та обмеження
- Підготувати БД для додавання даних

**Перевірка**: Виконав SELECT команди, щоб переконатися, що таблиці створені правильно.

### 3. Додавання даних (insert.sql)

Я виконав операції INSERT, щоб:
- Додати тестові дані до таблиць
- Перевірити обмеження типів даних
- Переконатися, що дані вставляються коректно

**Перевірка**: Використав SELECT для перегляду вставлених записів.

### 4. Вибірка даних (select.sql)

Я навчився писати SELECT запити для:
- Отримання всіх записів з таблиць
- Фільтрації даних за умовами (WHERE)

**Результати**: Всі запити видали очікувані результати.

### 5. Оновлення даних (update.sql)

Я виконав операції UPDATE, щоб:
- Змінювати значення полів за умовами WHERE
- Оновлювати записи з використанням виразів
- Забезпечувати цілісність даних через правильні умови

**Важливо**: Завжди використовував WHERE, щоб не обновити всі записи випадково.

### 6. Видалення даних (delete.sql)

Я виконав операції DELETE, щоб:
- Видаляти записи за конкретними умовами
- Безпечно видаляти дані через WHERE
- Перевіряти результати перед остаточним видаленням

**Практика**: Спочатку виконував SELECT з тією ж умовою, щоб побачити, які записи будуть видалені.

### Основні операції DML

#### SELECT - Вибірка даних
```sql
-- Отримання всіх записів
SELECT * FROM table_name;

-- Вибірка з умовами
SELECT column1, column2 FROM table_name WHERE condition;

-- Сортування та обмеження
SELECT * FROM table_name ORDER BY column_name LIMIT 10;
```

#### INSERT - Додавання даних
```sql
-- Вставлення одного запису
INSERT INTO table_name (col1, col2) VALUES (val1, val2);

-- Вставлення кількох записів
INSERT INTO table_name (col1, col2) VALUES 
  (val1, val2),
  (val3, val4);
```

#### UPDATE - Оновлення даних
```sql
-- Оновлення з умовою
UPDATE table_name SET column_name = new_value WHERE condition;

-- ЗАВЖДИ використовувати WHERE!
-- UPDATE без WHERE обновить ВСІ записи!
```

#### DELETE - Видалення даних
```sql
-- Видалення з умовою
DELETE FROM table_name WHERE condition;

-- ОБЕРЕЖНО: DELETE без WHERE видалить ВСІ записи!
-- Спочатку перевірте: SELECT * WHERE condition;
```
